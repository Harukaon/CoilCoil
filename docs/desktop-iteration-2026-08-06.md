# SuoCode Desktop 交互与预览迭代需求

日期：2026-08-06

## 目标

本轮完善 SuoCode Desktop 的对话回溯、多会话并行状态、三栏尺寸约束、右侧文件工作区、独立文件预览窗口、运行状态文案与模型性能可视化。

## 本轮实现范围

### 1. 对话区域

- 缩小 Agent 回复内容左侧留白，使窄中栏下仍能有效展示内容。
- 用户点击历史用户消息后，原地进入编辑状态。
- 编辑后按 Enter 提交，从该条消息位置回溯并继续对话。
- 本轮只接入 Pi 的线性回溯，不在 UI 暴露分叉选择、分支树或多分支管理。

### 2. 多项目与多会话并行

- Home 与多个挂载项目继续同时存在。
- 每个会话拥有独立的 Runtime 上下文和 Pi `AgentSession`，但统一承载在一个桌面 Runtime 进程内；切换项目或会话不会终止其他正在运行的 Agent。
- 允许在不同项目或会话中并行运行 Agent。
- 会话列表状态：
  - 正在运行：左侧显示动态 Loading。
  - 后台运行完成但尚未打开：左侧显示绿色圆点。
  - 用户打开后：恢复普通会话图标并清除未读完成状态。

### 3. 三栏尺寸

- 左栏最小宽度：40px。
- 中间对话栏最小宽度：315px。
- 右栏最小宽度：40px。
- 拖动任一分隔线时必须尊重上述三个最小值。

### 4. 右侧文件工作区

- 暂时移除 Todo、变更、终端 Tab，只保留文件 Tab。
- 文件树继续使用逐层懒加载：只读取根目录；用户展开文件夹时才读取该目录一层。
- 删除文件树内嵌底部预览。

### 5. 独立文件预览窗口

- 文件预览使用独立、非模态原生窗口，不阻塞主窗口交互。
- 预览窗口可自由拖动，可移出主窗口边界。
- 支持常见文本文件和脚本：TXT、JSON、JSONC、JS、TS、JSX、TSX、CSS、SCSS、LESS、Python、Shell、BAT、CMD、PowerShell、HTML、XML、YAML、TOML、INI、ENV、SQL、日志等。
- Markdown 支持“源码 / 渲染”切换。
- HTML 支持“源码 / 渲染”切换；渲染内容必须隔离脚本权限。
- PDF 支持原生 PDF 预览。
- 预览中的磁盘文件发生变化时，窗口实时更新。
- 不识别的文件左键点击时打开文件操作菜单，提供：
  - 在访达/系统文件管理器中显示。
  - 作为文本打开。
  - 删除文件（最后一项，危险样式，并要求确认）。

### 6. Agent 运行状态

- 替换普通旋转圈，使用具有 SuoCode 特征的动态 Loading。
- 运行期间轮换更自然、有趣的中文状态文案，例如“连接中”“工作中”“整理线索”“翻找文件”“冲浪中”“收尾中”。
- 工具执行和文本输出仍可覆盖为更准确的即时状态。

### 7. 性能状态增强

- 保留首字延迟、平均 Token 输出速度和上下文圆环。
- 在上下文圆环右侧增加性能信号指示器。
- 根据首字延迟与 Token/s 综合划分深绿、绿色、黄色、红色状态。
- 点击信号指示器显示近期每次模型请求的性能记录。
- 历史记录采用类似 GitHub 提交格的色块表达性能等级，并显示每次请求的首字、Token/s、输出 Token 和耗时。
- 性能记录必须由 Runtime/工作流真实数据驱动，并随会话持久化恢复。

## 本轮不实现，仅调研讨论

### A. 文件 Diff 渲染

- 调研 Pi 是否提供稳定、结构化的文件修改事件或 Diff 数据。
- 若 Pi 已提供，后续优先直接投影；若需要自行构建完整文件状态追踪，需重新评估维护与性能成本。

### B. 对话回溯时恢复磁盘修改

- 调研 Pi 回溯是否仅改变会话树，还是同时具备文件系统 Checkpoint。
- 调研上游是否使用 Git、Shadow Git、文件快照或补丁日志。
- 未确认安全、可恢复的上游机制前，不自行实现磁盘回滚。

## 验收要求

- TypeScript 检查、工作流测试、Runtime 烟测、打包版 Desktop 烟测全部通过。
- 增加自动化覆盖：懒加载目录、三栏最小宽度、历史消息回溯、多会话并行状态、独立预览窗口、文件实时刷新、性能历史恢复。
- 生成 macOS 打包产物并启动最新版本供人工验收。

## 追加校正（2026-08-06）

- 调整应用窗口大小时，不允许自动改写左栏或右栏宽度；栏宽只能由用户拖动栏分隔线修改。
- 外层窗口的最小宽度由当前平铺栏宽动态计算：中间区域至少保留 315px，左右栏在平铺状态下保持用户设定宽度。
- 性能历史改为 GitHub contribution 风格的小方格序列，每个方格代表一次请求。
- 请求的时间、首字延迟、输出速度和输出 Token 仅在悬浮具体方格时显示，不再常驻展示明细列表。
- 性能分级放宽：首字延迟在 20 秒内且输出速度不低于 10 tok/s 时归入黄色区间；仅更差的请求显示红色。
- 修正独立预览窗口在没有“大文件截断”警告时的 Grid 行错位，确保内容区域占满标题栏与状态栏之间的空间。
