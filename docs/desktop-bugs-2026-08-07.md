# CoilCoil Desktop 当前缺陷清单

本文档记录 2026-08-07 桌面端测试中确认的缺陷。这里的条目优先于新增大型功能；每项修复都应经过窄窗口、历史会话恢复和打包应用回归。

## 本轮已实现，待用户手测

- Workspace 的“显示更多/收起更多”改为居中的整行点击区域，不再只有小方块可点击。
- Todo/代理活动面板的整个标题空白区域都可展开或收起；Tab、停止按钮等内部控件仍保留独立操作。
- 右侧文件树的文件和文件夹统一支持右键菜单：`在访达中显示`、`移到废纸篓`。删除由主进程调用系统废纸篓并二次确认，且禁止对工作区根目录执行删除。
- 项目记忆在一次 Agent 请求完全 settled 后自动启动隔离的后台整理；同一项目后续对话继续通过现有 Pi 扩展注入 `MEMORY.md`。
- 本轮不改 Terminal 工作区；终端会话化、配色、拖放和进程清理需求按用户决定暂缓。

## P0：对话与历史消息

### 回溯后运行时面板仍显示旧分支数据

- 风险：历史消息编辑会改变 Pi Session 的活动叶节点；如果右侧运行时面板只累计会话事件，旧分支的 compaction、工具 Token 和上下文统计会继续残留。
- 目标：回溯导航完成时同步发布新的 `activeLeafId`、`sessionRevision` 和完整运行时快照；聊天与右侧栏同时切换。
- 验收：回溯后无需等待新回复结束，旧分支总结立即退出“当前上下文”；迟到的旧 revision 事件不会重新污染界面。

### 工具活动摘要箭头位置

- 当前问题：展开箭头被 `space-between` 推到了整行最右侧，摘要文字和交互目标相距过远。
- 目标：箭头紧跟在“思考了 X 次、运行了 X 个命令……”摘要文字之后。
- 验收：长、短摘要都保持自然间距；点击摘要文字或箭头均可展开；不会覆盖正文。

### Markdown 表格横向滚动

- 当前问题：窄栏下表格可能被强制压缩、裁切或撑破聊天容器。
- 目标：Markdown 表格外层使用独立的横向滚动容器，保留列的可读最小宽度。
- 验收：聊天栏缩到最小宽度时，页面本身不横向溢出，只有表格区域出现细横向滚动条。

### 小宽度正文溢出

- 当前问题：普通文本、代码和工具结果在窄聊天栏下仍可能被右侧面板遮挡或裁切。
- 目标：正文允许自然换行；不可断开的路径、命令和代码只在自己的容器内滚动。
- 验收：315px 中栏下正文不消失、不越过分栏线，代码块和表格独立滚动。

### 历史图片恢复

- 当前问题：带图片的用户消息重新打开会话后，图片没有回显。
- 目标：从 Pi 会话消息中恢复图片内容和顺序，并与首次发送时使用同一个消息组件。
- 验收：重启应用、切换会话、切换工作区后，历史图片仍可见并可打开预览。

### 历史消息编辑支持图片

- 当前问题：历史消息编辑框无法粘贴图片，也不能完整恢复原消息附件。
- 目标：历史编辑器和底部 Composer 复用同一套粘贴、校验、压缩和附件状态逻辑。
- 验收：进入编辑时保留原图片；可粘贴新图片、移除图片；取消编辑可完整恢复；发送后从该消息继续会话。

### 拖放目标必须跟随当前编辑器

- 当前问题：从文件树拖放文件或文件夹时，路径总是进入底部 Composer，即使用户正在编辑历史消息。
- 目标：拖放到哪个文本编辑器，就向哪个编辑器插入带单引号的绝对路径，例如 `'/path/to/project/CoilCoil'`。
- 不再实现附件卡片、特殊标记或富文本引用；路径始终是可直接编辑、复制和发送的纯文本。
- 验收：文件和文件夹都支持；路径中含空格或中文也可正确发送；历史编辑和底部 Composer 互不串写。

### 历史回溯中间态清理

- 当前问题：从历史消息重新发送后，旧的用户消息或回复会短暂重复，直到模型回复结束才恢复正常。
- 目标：确认回溯后立即按目标消息截断 UI 时间线，再开始新请求。
- 提示文案应说明：会话将从这里继续，但不会恢复工作区中已修改的文件。按钮为“继续”“不再提醒”“取消”。
- 编辑历史消息可能降低上游提示缓存命中率，可在编辑框下用低干扰小字提示，不参与阻断。

## P0：Composer 与状态栏

### 从设置页返回后聊天跳到顶部

- 当前问题：设置页会替换工作区，返回后 Conversation 时间线重新挂载，但没有重新执行定位到底部的逻辑。
- 目标：从设置或主工作区技能页返回当前聊天时，立即定位到最新消息。
- 验收：长历史会话在模型空闲和运行中分别切换设置页，返回后都停在最新消息；不会产生平滑滚动抖动。

### 无数据时隐藏性能指标

- 当前问题：没有数据时显示 `首字 — · — tok/s`，属于无意义占位。
- 目标：首字延迟、输出速度没有有效数值时隐藏对应指标；两者都没有时隐藏整段性能摘要。
- 验收：等待首 token、连接失败、历史旧会话和不返回 usage 的供应商均不显示破折号占位。

### Todo/活动面板遮挡会话底部

- 当前问题：Todo 展开后可能覆盖最后一段会话，而且聊天容器无法继续向下滚动到安全位置。
- 目标：聊天滚动区为 Composer 和活动面板预留动态底部空间；只有面板本身遮挡，透明外层不得拦截或覆盖背景。
- 验收：Todo 折叠和展开时都能把最后一条消息完整滚动到可视区域。

## P1：工作区与会话列表

### 会话右键归档

- Workspace 下的会话行需要右键菜单。
- 产品不提供“删除会话”概念；统一使用“归档”。
- 归档后从默认列表隐藏，但会话数据仍可恢复，后续提供归档入口。

### 工作区展开行为

- 点击文件夹行或文件夹图标只负责展开/折叠，不得自动切换到该工作区的第一条会话。
- 文件夹图标悬浮时显示折叠箭头；右侧位置使用“+”创建该工作区下的临时“新对话”。
- 临时会话未发送内容就切走时自动丢弃；发送后转为持久会话。
- 每个工作区默认最多显示 4 条会话，更多内容通过“…”展开。
- 相邻工作区分组之间必须有可感知间距，不能与上一组最后一条会话贴合。

## P1：连接与错误显示

### Connection error 工具摘要

- 请求失败时，已经发生的 reasoning、命令和工具事件仍应按真实顺序保留。
- 错误消息作为该次 assistant turn 的结束状态展示，不应破坏摘要展开、折叠或后续继续对话。
- 连接错误不生成虚假的性能指标。

## P0：子 Agent 后台进程窗口泄漏

### macOS Dock 出现多个 `exec` 应用图标

- 当前问题：运行子 Agent 时，macOS Dock 会出现一个或多个名为 `exec` 的临时应用图标。子 Agent 数量增加时图标也会增加。
- 原因方向：后台 worker 可能直接使用 Electron 应用可执行文件启动 Node/Pi CLI，macOS 因而把每个 worker 识别为新的 GUI 应用实例，而不是无界面的后台子进程。
- 目标：子 Agent、memory worker 和其他 Runtime worker 必须使用真正的无界面进程启动方式，不注册 Dock 应用，不创建窗口，不激活应用。
- 实现审查：
  - 检查打包环境下 `process.execPath` 是否指向 Electron/CoilCoil 可执行文件。
  - Electron 可执行文件承载 Node worker 时，确保使用正确的 Node 模式环境和后台启动参数；如果仍会注册 GUI 实例，应改用安装包内独立的 Node sidecar/runtime launcher。
  - worker 的 stdio、IPC、退出码和进程组仍需保留，不能通过脱离管理来隐藏图标。
  - 子 Agent 停止、异常退出或主应用退出后，必须清理对应 worker，不能留下孤儿进程。
- 验收：
  1. 同时启动 1 个、3 个和更多子 Agent，Dock 中始终只有一个 CoilCoil 图标。
  2. 不出现 `exec`、Electron 或其他临时应用图标。
  3. 子 Agent 启动过程中不弹窗、不抢焦点、不切换当前 Space。
  4. 子 Agent 的流式事件、停止操作和退出状态保持正常。
  5. 打包应用和开发模式分别回归。

## 回归矩阵

每次完成本清单中的一组修复，至少验证：

1. 新会话首次发送。
2. 历史会话恢复和重启应用恢复。
3. 中文输入法组合输入与回车发送。
4. 图片粘贴、图片历史恢复。
5. 文件和文件夹拖入底部 Composer。
6. 文件和文件夹拖入历史消息编辑器。
7. 中栏 315px、左右栏 40px 的极窄布局。
8. Todo 展开、折叠与聊天滚动。
9. Markdown 长表格、长路径、代码块。
10. 供应商连接失败和用户主动中止。
11. 并发子 Agent 不产生额外 Dock 图标、窗口或孤儿进程。
