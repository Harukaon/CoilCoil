# Applications

- `desktop` — the complete Electron and React CoilCoil Agent workspace.
- `cli` — the terminal CoilCoil Agent.

Both applications use `@coilcoil/runtime-core`, `@coilcoil/runtime-protocol`, `@coilcoil/runtime-server`, the bundled workflow, and the vendored Pi source. Product behavior is implemented in shared packages instead of duplicated between surfaces.
